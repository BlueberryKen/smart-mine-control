# ⛏️ Smart Mine Control System

An ESP32-based industrial safety and telemetry control system featuring a web-based dashboard for real-time monitoring and remote actuation of mining environments.

## 🚀 Key Features
- **ESP32 Microcontroller Core:** Real-time sensor processing and wireless transmission.
- **Web-Based Telemetry Dashboard:** Live data visualization for environmental gases, temperature, and ventilation status.
- **Automated Hazard Control:** Automated triggers for emergency ventilation fans and alert sirens during threshold breaches.

## 🛠️ Tech Stack & Hardware
- **Hardware:** ESP32, MQ Gas Sensors, Temperature/Humidity Sensors, Relay Modules
- **Protocols:** HTTP/WebSockets, Wi-Fi, UART
- **Interface:** HTML5, CSS3, JavaScript Web Dashboard
